# CrimeWatch — Crime Data Analytics Dashboard (Frontend)

A responsive React + Vite dashboard prototype with a dark navy and red-accented visual design.

## Requirements
- Node.js 20.19+ or 22.12+ recommended (Node.js 24 is supported)
- npm

## Run in VS Code
1. Extract the ZIP file.
2. Open the extracted `CrimeAnalyticsDashboard` folder in VS Code.
3. Open **Terminal → New Terminal**.
4. Run:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local URL Vite prints in the terminal (usually `http://localhost:5173`).

## Included
- Overview dashboard and sidebar navigation
- Summary cards and responsive charts
- Crime category donut chart
- Searchable/filterable recent reports table
- Export filtered demo reports to CSV
- Responsive mobile navigation
- Sample/illustrative data only

## Important
This is frontend-only. It does not yet connect to Spring Boot or MySQL. The figures and case records are fictional illustrative demo data and must not be used for real-world decisions. Google Fonts are loaded online; the rest of the app is bundled locally after npm dependencies are installed.
